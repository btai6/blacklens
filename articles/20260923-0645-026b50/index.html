古代那些想變白的女人，命是用鉛換來的。

版主　渡鴉

1870年代，一盒「御園白粉」的主成分就是碳酸鉛。那時候的女人追求的是一種慘白到發青的質感，鉛粉一斤才幾個錢？開採出來，磨細，裝盒，溢價幾十倍在賣。她們用久了皮膚會發黑、牙齒脫落、最後神經系統崩潰。這不叫美容，這叫慢性服毒。現在我們笑她們傻，但把現在專櫃上那些動輒五、六千塊的亮白精華液拆開來看，結構其實沒什麼長進。

一瓶 30ml 的亮白精華，如果你看過它的後台原料報價單，心臟會停一拍。菸鹼醯胺（Niacinamide）這種萬金油成分，純度 99% 的原料，一公斤才幾百塊台幣。算下來，妳手上那瓶精華液裡的有效成分成本可能連十塊錢都不到。剩下的全是水、增稠劑、防腐劑，還有妳為了那個華麗包裝盒付出的「尊榮感」。

那些宣稱能抑制黑色素的神奇複方，行銷話術層層疊疊。說什麼「極致透亮」、「斷黑科技」，剝掉這些修飾語，底層邏輯就是 2% 的傳明酸加上一點點維生素 C 衍生物。傳明酸在藥局一排才多少錢？原料成本低到連報表都不想特別列出來。

一百多年前的鉛粉，成本在於礦石開採與人力研磨；現在的精華液，成本在於那個請了國際巨星代言的廣告預算，還有百貨公司專櫃那坪數貴得嚇人的租金。妳付的一百塊錢裡，大約有七十塊是在幫品牌付廣告費，二十塊是通路的利潤，剩下的十塊錢裡，包裝瓶子可能佔了八塊，裡面那管液體，兩塊錢都嫌多。

明治時期的女人因為含鉛的妝粉導致鉛中毒，現代女人則是因為對「白」的偏執，在臉上塗抹大量高濃度的酸類跟各種來路不明的複方。有些診所推的點滴，裡面放的高劑量維生素 C 跟傳明酸，成分跟那些精華液大同小異。打進血管裡，確實快，但代謝壓力全在肝腎。

很多號稱能「瞬白」的療程，背後是用高濃度的果酸先幫妳剝掉一層皮，讓底下的新鮮組織露出來。這種白，是受傷後的紅腫退去後的錯覺。這跟當年鉛粉覆蓋在臉上的邏輯沒兩樣，都是在透支皮膚的防禦力。

妳以為科技進步了，其實只是毒性變隱晦了。以前是直接給妳金屬中毒，現在是給妳發炎後的色素沈澱。

看看那些成分表，排在第一位的是 Aqua，第二位通常是甘油。那些聽起來很厲害的植物萃取，通常排在防腐劑後面，濃度低到只有 0.01% 甚至更低。這種濃度在實驗室裡連細菌都殺不死，卻能在行銷文案裡被寫成「深層修護的神奇力量」。

妳去專櫃試用的時候，覺得皮膚立刻變滑變亮，那通常是矽靈和雲母粉的功勞。矽靈填補了毛孔坑洞，雲母粉反射了燈光。這跟明治時代的鉛粉一樣，都是物理性的遮蓋，只是現代的化學合成技術讓它摸起來不那麼厚重，讓妳覺得那是「吸收」了。

這種毛利結構支撐著整個醫美與美妝帝國。如果大家都不追求那種不自然的白，這棟大樓第二天就會塌一半。一瓶成本幾十塊的液體，標價四千五，這就是現代鍊金術。當年明治政府發布鉛粉禁令，是因為死人死得太難看。現在沒人會發布美白禁令，因為這種收割方式溫柔得多，妳頂多是皮膚變薄、變敏感，然後再去買下一瓶號稱能「舒緩敏感」的修護霜。

說到底，我們跟一百多年前那些往臉上抹鉛粉的女人，處境差不了多少。

同樣是在為了一個虛幻的標準，支付超額的代價。只是現在的商人更聰明，他們不直接賣鉛，他們賣妳一個關於「透亮」的夢想，然後在妳刷卡的時候，輕聲告訴妳這叫投資。
