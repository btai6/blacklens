原料桶一公斤不到五十美金的純化胜肽，裝進三十毫升的瓶子加水就能溢價兩百倍。

版主　渡鴉

原料桶裝的一公斤純化胜肽，在國際報價單上最貴不過六十美金，這種東西進了實驗室，兌點去離子水、加兩滴增稠劑和防腐劑，分裝成三十毫升的小棕瓶，換個法文名字就能賣妳六千塊。

這筆帳算起來很有趣，三十毫升裡真正有效的純胜肽濃度通常不到 0.005%，剩下 99% 都是水和行銷費。妳以為在修護基底膜，實際上是在幫品牌的百貨專櫃付電費。

Thermage FLX 一顆探頭的進價成本是固定的，診所開價六萬還是十二萬，差別在於諮詢師的底薪和裝潢的折舊率。機器本身不騙人，騙人的是那句「能量開越高效果越好」。

皮膚耐受度是有極限的，就像妳拿噴火槍烤牛排，烤焦了不代表它熟得比較透。高能量帶來的組織水腫會讓妳在術後一週看起來臉部飽滿，等水腫退了，妳才發現那是假象。

有些號稱含有高濃度 PDRN 的針劑，原料來源甚至不是鮭魚，而是成本更低的雜魚。成分表上寫得天花亂墜，但在質譜儀下原形畢露，那些所謂的「專利萃取」只是為了規避成分透明化的修辭。

某些診所推銷的「客製化點滴」，一袋生理食鹽水加點維他命 C 和傳明酸，成本不到兩百台幣。賣妳三千塊的時候，他們會說是「抗衰老雞尾酒療法」，其實妳回家多吃兩顆奇異果效果差不多。

CaHA 這種填充物在國外的定價，換算下來只有台灣的一半。價差消失在所謂的「大師手法」和「限量配額」裡。這行最喜歡用稀缺性來包裝暴利，好像少了這一支妳的法令紋就會掉到下巴。

行銷話術最愛用的邏輯漏洞，就是把「體外實驗數據」直接等同於「人體塗抹效果」。在培養皿裡能讓細胞增生，不代表妳隔著厚厚的角質層塗兩下就能逆齡。

角質層的屏障功能就是為了擋住外界物質，如果胜肽隨便塗塗就能滲透進真皮層，那妳每天洗澡不就全身吸滿了自來水裡的氯？

妳看那些打著「醫療級」旗號的護膚品，包裝越素、價格越高。其實就是利用妳對專業的敬畏感。他們把原料桶裡的胜肽稀釋再稀釋，最後賣的是一種「我用得很專業」的心理暗示。

有些診所會叫妳 PicoSure 打完一定要搭配某種特定的生長因子導入，不然效果會打折。事實上，那是因為雷射把皮膚打紅了，他們怕妳回家過敏找麻煩，先收妳一筆錢買個保險。

Ultherapy 也是一樣，明明機器設定的參數就那幾個，偏偏有人要發明什麼「多層次精準打法」。這種名詞聽起來越高級，溢價空間就越大，其實只是把探頭貼緊一點而已。

這圈子最不缺的就是新名詞。今天叫逆時針，明天叫少女針。說穿了，成分不是 PLLA 就是 PCL，換個包裝和行銷策略，價格又能再翻一倍。

妳在社群軟體上看到的那些術前術後對比照，八成是靠光線和角度喬出來的。左邊燈光打暗、嘴角放鬆，右邊燈光全開、用力微笑。這種視覺魔術，妳我都看過，卻還是有人願意掏錢。

如果一項療程宣稱能解決妳臉上所有的問題，從毛孔到鬆弛，那它通常什麼都解決不了。科學是有邊界的，醫美機器也是。超過邊界的承諾，都是為了讓妳刷卡。

下次看到那些寫著滿滿胜肽名稱的成分表，記得先算算那幾十美金一公斤的原料。妳買的不是青春，是廠商精算後的利潤結構。

妳以為在投資未來，其實只是在消化過剩的原料產能。當水變成黃金，唯一的奇蹟只發生在品牌的財報上。
