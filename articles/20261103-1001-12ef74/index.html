一公斤的高純度左旋維他命 C 原料藥粉，在化工大宗交易市場的報價大概落在 20 到 40 美金。

版主　渡鴉

換算成妳手上那瓶 30ml、濃度標榜 15% 的精華液，裡面的維他命 C 核心粉末成本大約是台幣 5 塊錢。加上純水、甘油、一點穩定劑和防腐劑，那一管液體的內容物價值，通常撐不到一個超商御飯糰的價格。

妳在櫃檯刷了三千塊，扣掉那個手感厚實的深色玻璃瓶和燙金紙盒，剩下的 2900 塊都在幫品牌支付百貨公司的抽成、那個皮膚好到發亮的代言人酬勞，還有妳在社群媒體上看到的每一則推播廣告費。

這就是維他命 C 市場最荒謬的邏輯漏洞。品牌不停強調「高濃度」和「不穩定性」，把一種極其廉價的基礎化學物質包裝成稀缺的煉金術。

有些實驗室數據會告訴妳，15% 是吸收率的黃金比例，再高就會刺激皮膚，再低就沒效果。但他們沒說的是，維他命 C 一旦接觸水分，氧化鐘就開始倒數。妳買回家第一週它是淺黃色的，很有效；第三週變成深橘色，那是去氫抗壞血酸，除了讓妳角質層染成難看的土黃色，對膠原蛋白一點幫助都沒有。

有些品牌改用衍生物，像是維他命 C 磷酸鎂鹽或乙基維他命 C。這類原料穩定多了，成本卻比純左旋 C 貴上幾倍。結果更有趣了，品牌為了維持利潤結構，會把衍生物的濃度壓到 1% 甚至更低，然後在包裝上寫「添加維他命 C 誘導體」，利用資訊差讓妳以為買到了更高級的科技。

如果這瓶精華液裡還加了 1% 的 Vitamin E 和 0.5% 的阿魏酸，品牌通常會宣稱這是「黃金抗氧化三角」。阿魏酸確實能讓維他命 C 的穩定性提升不少，但這三種成分加起來的原料總價，依然很難突破台幣 15 塊。

溢價兩百倍的生意，在醫美護膚圈甚至不算最狠的。

妳去診所做導入，護士幫妳拆開一支安瓶，那支安瓶的進貨價可能只有 80 塊。妳付了 2500 塊，躺在床上二十分鐘。診所的邏輯是，他們替妳承擔了產品氧化的風險，並且用電導儀器強迫這些極性分子進到妳的皮層。

但妳知道嗎？很多所謂的「導入專用」精華，為了追求在儀器下不結塊、好推勻，加了大量的增稠劑。那些大分子聚合物塞在妳的毛孔表面，反而阻礙了那 15% 維他命 C 的滲透。妳以為是在補水，其實只是在塗膠水。

各國定價也是一場心理戰。同一款 15% 的維他命 C 精華，在美國亞馬遜可能賣 30 美金，進了百貨專櫃就變成 100 美金。這 70 美金的價差，買的是妳對「專業感」的集體焦慮。

很多人問我，既然原料這麼便宜，為什麼不自己買粉末回來調？

妳沒辦法在家裡的廚房搞定 pH 值。左旋 C 必須在 pH 3.5 以下才能穿透皮膚屏障，那個酸度操作不好就是居家換膚，隔天妳的臉會像煮熟的蝦子一樣脫皮。品牌賣的是那個「精準踩在毀容邊緣」的配方平衡，這也是他們唯一敢收妳兩百倍溢價的遮羞布。

我們這群人習慣看成分表的前五名。如果第一名是水，第二名是丙二醇，第三名才是維他命 C，這瓶東西的生產成本結構就非常透明。剩下的部分，全看妳願意為了那個品牌 Logo 提供的心理按摩付多少錢。

當妳看到廣告標榜「航太級穩定技術」或「奈米封裝專利」時，通常意味著這瓶精華液的行銷預算佔了總預算的 70%。

真正高級的原料廠，比如德國或日本的那幾家，生產出來的維他命 C 確實雜質更少。但那種價差在最終零售價面前，依然微不足道。就像妳買一輛法拉利，輪胎是用米其林還是倍耐力，對整車售價的影響微乎其微。

大家都在追求那個 15% 的數字，卻很少人去算那 85% 的溢價到底流向了哪裡。妳付出的每一塊錢，只有不到五分錢是真的作用在妳的黑色素上。

這就是護膚品工業的冷酷現實。妳買的不是化學反應，而是一個關於「我正在變好」的昂貴幻覺。那瓶變色的精華液即便失效了，只要瓶子還在那裡，只要妳還記得廣告裡的台詞，妳就會覺得照鏡子時皮膚亮了一階。

數字從來不會騙人，會騙人的是我們對奇蹟的渴望。當妳下次看著那瓶 15% 的精華液，算算那 5 塊錢的粉末，也許妳會對自己的錢包溫柔一點。
