純維他命C精華液變色後的折舊率與角質染色偽裝術

版主　渡鴉

打開那瓶標榜 20% 純 L-抗壞血酸的棕色玻璃瓶，發現液體已經從淺香檳色變成泰式奶茶那種渾濁的橘黃，妳還在催眠自己那是「高效發揮」。

原料市場上，一公斤 99% 純度的 L-Ascorbic Acid 報價大概就在幾十塊美金上下，分裝成 30ml 賣妳三千塊，這中間高達 90% 以上的毛利，買的就是那個還沒氧化掉的「時效性」。

當精華液開始轉黃，裡面的去氫抗壞血酸（DHAA）含量就開始飆升。這玩意兒不僅失去抗氧化能力，更麻煩的是它會進一步降解成赤蘚酮糖（Erythrulose）。

這名字聽起來陌生？去翻翻助曬產品的成分表，它跟 DHA 助曬劑是近親。這就是為什麼妳連續塗幾天變色的 C 之後，照鏡子覺得臉色發黃。那不是皮膚變黑，是妳的角質層被染色了，像是抹了一層劣質的仿曬霜。

很多大牌子會在配方裡加黃色色素，或者利用阿魏酸（Ferulic Acid）本身的草本顏色來掩蓋氧化進程。這招很高明，讓妳分不清楚這瓶東西到底死透了沒。

純 C 的穩定性實驗數據很殘酷，在室溫 25 度、開蓋接觸空氣的條件下，有些配方在第四週，活性成分就可能掉到剩不到標示值的一半。妳以為妳在省著用，其實妳是在用專櫃的價格買一瓶開架強度的廢水。

所謂的 15% 或 20% 濃度，那是它在出廠那一刻的巔峰。只要顏色變深，它的抗氧價值就該打三折。如果已經變成紅褐色，那根本不該上臉，裡面的酸性環境加上氧化產物，除了增加屏障受損的風險，對膠原蛋白一點貢獻都沒有。

有些諮詢師會跟妳說變色了也能擦脖子，別聽這種鬼話。脖子皮膚比臉還薄，更容易因為氧化產物的刺激而發癢。

藥妝店那些打折出清的 C 精華，沒事別去撿便宜。看一眼製造日期，如果是半年以前生產的，哪怕它是真空包裝，穿透包材進入的微量氧氣也夠它在瓶子裡慢慢「腐爛」了。

妳花錢買的是那個能中和自由基的電子，不是買一瓶過期的染色劑。

有些實驗室數據顯示，當純 C 完全氧化後，它產生的副產物反而會誘導氧化壓力。這邏輯很諷刺，妳為了抗老去買它，結果因為捨不得扔，最後反而加速了皮膚的發炎反應。

市場上那些賣超貴的專利配方，說穿了就是在玩溶劑遊戲。用多元醇取代水，或者把 pH 值壓到 3.0 以下，為了維持那口氣，犧牲的是使用感。那種黏膩、刺痛、像鐵鏽一樣的味道，就是這場化學拔河的代價。

下回看到精華液變深，直接倒進馬桶吧。馬桶沒感覺，但妳的臉會感謝妳沒把它當成化學廢料處理廠。

很多人問為什麼不用 C 的衍生物？因為衍生物轉化率低得感人。磷酸鎂鹽（MAP）或葡萄糖苷（AA2G）穩定是穩定，但在皮膚裡轉化成純 C 的效率有時候連 10% 都不到。妳要嘛選一個隨時會自爆的真英雄，要嘛選一個穿著盔甲但沒戰鬥力的路人。

這就是純 C 產品的宿命，從出廠那一秒開始，它就在通往報廢的倒數計時。妳買的不是護膚品，是一場與時間賽跑的賭博。

這場局裡，最聰明的做法不是找最貴的，而是找最新鮮、容量最小、能在一個月內徹底用完的。

超過 30ml 的純 C 精華都是在耍流氓。除非妳打算拿來擦全身，否則在它變成泰奶色之前，妳絕對用不完。

剩下一半捨不得丟的人，最後都在安慰自己那是「自然的草本色澤」。算了吧，數字不會騙人，化學反應更不會。

當妳看著那瓶橘褐色的液體，想想妳付出的真金白銀，再想想它在妳角質層留下的偽裝染色。這筆帳怎麼算，折舊率都已經破表了。
